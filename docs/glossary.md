# Glossary — Mobile Money Tiered KYC Limits

Educational terminology for **mobile money transaction limits**, tiered KYC wallet limits, and velocity controls. Definitions are industry-oriented; regulator and vendor labels vary.

## Core Terms

| Term | Definition |
|------|------------|
| **KYC** | Know Your Customer: identifying and verifying a customer |
| **Tiered KYC** | Graduated identification levels, each unlocking higher limits |
| **Proportionate KYC** | Regulatory principle of matching checks to risk and value |
| **Limit profile** | Configured set of caps for a tier, product, and channel |
| **Balance cap** | Maximum amount a wallet may hold at any time |
| **Per-transaction limit** | Maximum amount for a single transaction |
| **Velocity limit** | Cap on cumulative amount or count within a time window |
| **Rolling window** | Period measured backwards from now (for example, last 24 hours) |
| **Calendar window** | Period aligned to calendar boundaries (for example, this month) |
| **Receiver-side check** | Verifying the recipient can accept a credit without breaching their cap |
| **Tier upgrade** | Promotion to a higher tier after verified documents or checks |
| **Tier demotion / freeze** | Reduction or suspension of limits after a risk event |
| **Limit override** | Approved, time-bound exception to a standard limit |
| **Reason code** | Machine-readable decline cause shown to channels and support |
| **AML** | Anti-money laundering obligations that limits help enforce |
